For AI agents

Everything an agent needs to install, configure and check these mods for a person. Plain text versions: llms.txt (index) and llms-full.txt (everything on one page).

Facts

  • Marketplace: Guhan-SenSam/claude-terrarium (GitHub). Marketplace name once added: claude-terrarium.
  • Mods: thinking-weather, system-monitor, turn-receipt, pins. Each installs alone.
  • Needs Claude Code with mods (function hooks); built and tested on 2.1.325.
  • Visual parts draw in the desktop app. The terminal shows text parts only (system-monitor's text bars, turn-receipt, pins).
  • system-monitor reads Linux /proc; it does nothing useful on macOS or Windows hosts.

Install for the person

  1. Ask which mods they want, and whether every session should have them (user scope) or only this project.
  2. Run, for each mod: 
    claude plugin install <mod> --marketplace Guhan-SenSam/claude-terrarium --scope user
  3. Check: claude plugin list shows <mod>@claude-terrarium as enabled.
  4. Tell the person to restart the session or run /reload-plugins; mods load at session start.

Configure thinking-weather's town

Real weather is off until a town is set. Setting one sends the town's name to Open-Meteo once, then coordinates rounded to about 10 km every 30 minutes, so ask the person before setting it. Either:

  • the person types /terrarium-weather place Town, Region, or
  • you call the tool mcp__thinking-weather__weather_place with {"town": "Town, Region"}, or
  • you run (the recommended way, it validates the value):
echo '{"place":"Tampa, Florida"}' | claude plugin configure thinking-weather@claude-terrarium --values-stdin

It is stored in ~/.claude/settings.json as:

{
  "pluginConfigs": {
    "thinking-weather@claude-terrarium": { "options": { "place": "Tampa, Florida" } }
  }
}

The key is <plugin>@<marketplace>. A copy loaded with --plugin-dir reads thinking-weather@inline instead.

Tools thinking-weather gives you

ToolInputUse
mcp__thinking-weather__weather_previewsky, season, holiday, era (each a name or "auto"), hour (0-24)Show the person a look; previews show clear weather. Pass "auto" to go back.
mcp__thinking-weather__weather_placetown or "off"Set or clear the real-weather town.
mcp__thinking-weather__weather_cycleseconds (10-600)Play a whole day sped up.

Your own tool calls bring Claude's storm in over the scene; that is the mod working, not a fault.

Troubleshooting

SymptomCause and fix
No backgroundThe terminal draws none; use the desktop app. After install or update, restart or /reload-plugins.
A command "registered but no hook answered it"A copy of the mod was unloaded mid-session. Restart the session.
Two bands or competing backgroundsAn installed copy and a development copy are both loaded. Remove the development copy.
Sky stays clear with a town setCheck /terrarium-weather now; the settings key must be thinking-weather@claude-terrarium.
No soundThe mods make none.
