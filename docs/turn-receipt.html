turn-receipt

A one-line receipt under each finished reply, so you can tell which turns did real work when you come back to a long session.

4m 12s · 23 tool calls · 2 agents · edited register.tsx, sample.ts +4 · 3.2k tokens out
  • Time: how long the turn took; a stopped turn reads interrupted after 1m 3s.
  • Tool calls and agents: every call in the turn, its subagents' included.
  • Files edited: the first two, then a count of the rest.
  • Tokens out: what the model wrote.

Shown in the desktop app, the terminal and the phone app, and kept for the last 30 sessions.

Install

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with Guhan-SenSam/claude-terrarium, then Add plugin and pick turn-receipt.

At a terminal prompt:

/plugin install turn-receipt --marketplace Guhan-SenSam/claude-terrarium

From a shell:

claude plugin install turn-receipt --marketplace Guhan-SenSam/claude-terrarium

Choose the user scope to load it in every session. Update with claude plugin update turn-receipt@claude-terrarium, then restart or run /reload-plugins.
