system-monitor

Live CPU, RAM and GPU meters in a band above the prompt, for watching heavy jobs while Claude works.

What it shows

  • A pixel chip, memory stick and graphics card, each followed by a bar of chunky segments and its reading.
  • Green under 70%, gold from 70%, lantern orange from 90%, with a stepped glow brighter as a reading climbs.
  • Warmer at dawn and dusk, dimmer at night with an amber glow.
  • A sleeping GPU (hybrid-graphics laptops) is left asleep, shown dimmed with a "z".
  • On a narrow prompt the bars shrink, then go, keeping icons and numbers. The terminal shows text bars.
  • /sysmon opens a pane with threads and load average, memory and swap, VRAM and GPU temperature.

Readings refresh every 2 seconds from /proc and nvidia-smi, all local. Linux only; the NVIDIA GPU is optional.

Install

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with Guhan-SenSam/claude-mods, then Add plugin and pick system-monitor.

At a terminal prompt:

/plugin install system-monitor --marketplace Guhan-SenSam/claude-mods

From a shell:

claude plugin install system-monitor --marketplace Guhan-SenSam/claude-mods

Choose the user scope to load it in every session. Update with claude plugin update system-monitor@claude-mods, then restart or run /reload-plugins.
