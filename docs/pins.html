pins

Keep the replies that matter. Pin a plan, a command or an answer and it stays in a Pinned pane.

  • Desktop: hover a reply and press Pin at its bottom-right; a pinned reply keeps an Unpin.
  • Phone and terminal: /terrarium-pins add pins Claude's last reply.
  • /terrarium-pins shows or hides the pane: each pinned reply in full, newest first, with when it was pinned.

Pins come back when you reopen any of your last 30 sessions.

Install

In the desktop app: click + next to the prompt box, then Plugins, Add marketplace with Guhan-SenSam/claude-terrarium, then Add plugin and pick pins.

At a terminal prompt:

/plugin install pins --marketplace Guhan-SenSam/claude-terrarium

From a shell:

claude plugin install pins --marketplace Guhan-SenSam/claude-terrarium

Choose the user scope to load it in every session. Update with claude plugin update pins@claude-terrarium, then restart or run /reload-plugins.
